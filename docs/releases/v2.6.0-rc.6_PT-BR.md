# Surgical DevOps v2.6.0-rc.6

## Correção da publicação de pré-release

A RC.6 adiciona o canal explícito de distribuição npm `--tag next`. A tag imutável RC.5 passou pela qualificação Linux, macOS e Windows, mas o npm rejeitou a publicação antes da criação do pacote porque o canal de pré-release não estava explícito.


English: [v2.6.0-rc.6.md](./v2.6.0-rc.6.md)

Status: **recuperação hermética de candidato a release**

Este candidato preserva todo o escopo governado de produto da v2.6.0-rc.4 e
corrige somente o isolamento dos testes de release. A tag imutável
v2.6.0-rc.4 revelou quinze testes de CLI, onboarding e instalação que ainda
dependiam do checkout físico do release. Nenhum pacote npm ou GitHub Release
foi publicado a partir daquela tag falha.

Os testes afetados agora executam em repositórios Git herméticos descartáveis.
A construção do pacote permanece vinculada à árvore-fonte real, enquanto o CLI
instalado executa dentro de uma branch física nomeada. A produção continua
rejeitando HEAD destacado; nenhum invariante operacional, fronteira de autoridade
ou comportamento fail-closed foi reduzido.

Baseline predecessor qualificado:
`56da715284704f227675961d476e19acce6e9fa3`

Workflow canônico:
[33286652480](https://github.com/bonushora/surgical-dev-ops/actions/runs/33286652480)

```bash
npm ci
npm test
node --test tests/accelerator/npm-unified-installation.test.js
npm pack --dry-run
```

O checkout normal e um clone real em HEAD destacado descobriram 1139 testes:
1134 aprovados, nenhuma falha e cinco testes específicos de plataforma ignorados.

Ubuntu, macOS e Windows devem passar no pull request, no main mesclado e na tag
exata antes da publicação npm. Manifest CAS, autorização assinada, anti-replay
linearizável G1-G10 e a campanha adversarial incremental permanecem inalterados.

Isto não é prova de segurança absoluta e não é uma auditoria independente concluída.
