# Installation

Install the supplied SHA-256-identified npm artifact on Linux, macOS, or Windows.
Do not clone either development repository. Verify the artifact hash against its
manifest, then install with the organization-approved npm client. External
publication and artifact signing are not part of this beta runner; unsigned
artifacts must be transported through an approved customer channel.

Runtime content excludes tests, Git history, developer state, private keys, and
qualification fixtures. `surgical version --json` reports component and protocol
versions.
