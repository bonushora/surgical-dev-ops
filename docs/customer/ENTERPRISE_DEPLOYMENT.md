# Enterprise deployment

Enterprise pilot supports deterministic configuration, telemetry-off operation,
bounded evidence export, separate operator/approver concepts, multiple repository
isolation, backup/restore of non-authority state, and sanitized support bundles.

OIDC, SAML, directory integration, centralized policy distribution, external
secret stores, SIEM export, and enforced institutional separation of duties are
adapter boundaries, not implemented claims. Enterprise production readiness is
not claimed.
