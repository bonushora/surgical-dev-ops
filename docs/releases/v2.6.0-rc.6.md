# Surgical DevOps v2.6.0-rc.6

## Prerelease publication repair

RC.6 adds the explicit npm prerelease distribution channel `--tag next`. The immutable RC.5 tag passed Linux, macOS, and Windows qualification, but npm rejected publication before package creation because the prerelease channel was not explicit.


Português: [v2.6.0-rc.6_PT-BR.md](./v2.6.0-rc.6_PT-BR.md)

Status: **hermetic release-candidate recovery**

This candidate preserves the complete governed v2.6.0-rc.4 product scope and
corrects only release-test isolation. The immutable v2.6.0-rc.4 tag exposed
fifteen CLI, onboarding and installation tests that still depended on the
physical release checkout. No npm package or GitHub Release was published from
that failed tag.

The affected tests now execute against disposable hermetic Git repositories.
Package construction remains rooted in the real source tree, while the installed
CLI executes inside a named physical branch. Production continues to reject
detached HEAD; no operational invariant, authority boundary or fail-closed
behavior is weakened.
