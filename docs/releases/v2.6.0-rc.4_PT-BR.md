# Surgical DevOps v2.6.0-rc.4

English: [v2.6.0-rc.4.md](./v2.6.0-rc.4.md)

Status: **recuperação de candidato a release**

Este candidato contém todo o escopo governado G1-G10 da v2.6.0-rc.3 e uma
correção de isolamento de testes. A tag imutável v2.6.0-rc.3 revelou que quatro
testes de apresentação da ativação dependiam de uma branch nomeada e falhavam
no checkout destacado da tag em Ubuntu, macOS e Windows. Nenhum pacote npm ou
GitHub Release foi publicado a partir daquela tag falha.

A correção transfere esses testes de apresentação para repositórios Git
descartáveis com branch física `main`. A produção continua rejeitando HEAD
destacado; nenhum invariante operacional ou fronteira de autoridade foi reduzido.

Baseline predecessor qualificado: `ded6eaf`
Workflow canônico: [33278958374](https://github.com/bonushora/surgical-dev-ops/actions/runs/33278958374)

```bash
npm ci
npm test
node --test tests/accelerator/natural-assistance-cli.test.js
node --test tests/accelerator/natural-development-rc3-adversarial-readiness.test.js
npm pack --dry-run
```

Ubuntu, macOS e Windows devem passar no pull request, no main mesclado e na tag
exata antes da publicação npm. Manifest CAS, autorização assinada, fronteira
anti-replay G1-G10 e campanha adversarial incremental da rc.3 permanecem inalterados.

Isto não é prova de segurança absoluta e não é uma auditoria independente concluída.
