# Surgical DevOps v2.6.0-rc.6

## Correção da publicação de pré-release

A RC.6 adiciona o canal explícito de distribuição npm `--tag next`. A tag imutável RC.5 passou pela qualificação Linux, macOS e Windows, mas o npm rejeitou a publicação antes da criação do pacote porque o canal de pré-release não estava explícito.


English: [v2.6.0-rc.6.md](./v2.6.0-rc.6.md)

Status: **recuperação hermética de candidato a release**

Este candidato preserva todo o escopo governado de produto da v2.6.0-rc.4 e
corrige somente o isolamento dos testes de release. A tag imutável
v2.6.0-rc.4 revelou quinze testes de CLI, onboarding e instalação que ainda
dependiam do checkout físico do release. Nenhum pacote npm ou GitHub Release
foi publicado a partir daquela tag falha.

Os testes afetados agora executam em repositórios Git herméticos descartáveis.
A construção do pacote permanece vinculada à árvore-fonte real, enquanto o CLI
instalado executa dentro de uma branch física nomeada. A produção continua
rejeitando HEAD destacado; nenhum invariante operacional, fronteira de autoridade
ou comportamento fail-closed foi reduzido.

Baseline predecessor qualificado:
`56da715284704f227675961d476e19acce6e9fa3`

Workflow canônico:
[33286652480](https://github.com/bonushora/surgical-dev-ops/actions/runs/33286652480)

```bash
npm ci
npm test
node --test tests/accelerator/npm-unified-installation.test.js
npm pack --dry-run
```

O checkout normal e um clone real em HEAD destacado foram qualificados antes da
integração ADR-036/ADR-037. A qualificação local atual do gateway integrado
descobre 1206 testes: 1201 aprovados, nenhuma falha e cinco testes específicos
de plataforma ignorados.

## Qualificação local do gateway integrado ADR-036/ADR-037

A qualificação local do gateway NATURAL integrado é construída sobre o
checkpoint de NATURAL como padrão
`9ed86a443da18f923b60692d7446f1fd57d0a2da` e sobre o checkpoint governado de
workspace da ADR-034 `f56750eba3aa07b0426f56021c072a280468ea98`, que por sua vez
foi construído sobre o commit inicial da implementação ADR-034
`2f8d9e1aa40d0d7a127e966a28e475e0f89c4bb0`.

A implementação atual adiciona a missão governada NATURAL persistente da
ADR-036 e o gateway estruturado da ADR-037 ao runtime real. NATURAL consegue
projetar status da missão, plano vivo, alterações, testes, autoridade, journal e
resume governado enquanto requisições estruturadas do gateway invocam status de
workspace, busca governada, leitura governada, diff governado, execução
governada de testes e criação contextual de aprovação sem copy/paste manual. O
caminho de proposta ENGINEER e o caminho de comandos EXPERT permanecem
separados.

Suíte canônica local:
1206 testes descobertos; 1201 aprovados; nenhuma falha e cinco testes
específicos de plataforma ignorados.

Esta qualificação local não reivindica nova tag enviada, GitHub Release,
publicação npm nem substituição do predecessor com CI nativo publicado acima. O
próximo gate de publicação ainda exige Ubuntu, macOS e Windows verdes no commit
e na tag exatos enviados.

Ubuntu, macOS e Windows devem passar no pull request, no main mesclado e na tag
exata antes da publicação npm. Manifest CAS, autorização assinada, anti-replay
linearizável G1-G10 e a campanha adversarial incremental permanecem inalterados.

Isto não é prova de segurança absoluta e não é uma auditoria independente concluída.
