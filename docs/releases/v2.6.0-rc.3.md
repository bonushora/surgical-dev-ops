the v2.6.0-rc.2 adversarial baseline immutable.

## What changed

- NATURAL requests become exact immutable G1-G3 proposals before authority.
- Local human authority signs one content-bound, expiring G4 decision.
- G5 composes only matching evidence into the existing production R3 boundary.
- G6 validates the authoritative projection with one bounded correction ceiling.
- G7-G10 durably claim, reconcile, dispatch and consume authorization once.
- Every successful physical transition remains bound to journal and Manifest CAS evidence.
- The bilingual terminal exposes immediate progress, bounded latency and a
  unified NATURAL, ENGINEER and EXPERT installation.
- A real signed mutation was qualified in a temporary Git repository without
  changing the ordinary source repository, and replay was denied.
