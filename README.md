# 🥼 Surgical DevOps

Este repositório é a minha **Central da Verdade** para metodologias, processos e diretrizes de engenharia de software. Aqui catalogo frameworks autorais desenvolvidos para otimizar o fluxo de trabalho, mitigar erros e padronizar a colaboração cirúrgica entre humanos e Inteligências Artificiais.

A filosofia central aqui é: **intervenção cirúrgica baseada em evidências**, tratando modificações de código como procedimentos de precisão, e não como reescritas completas.

## ⚡ Como invocar o BH-SEP em qualquer IA (Comando Único)

Copie e cole a linha abaixo no início da sua conversa com o ChatGPT, Claude, Gemini ou Copilot para carregar o protocolo instantaneamente via link remoto:

> **Acesse a URL raw.githubusercontent.com/bonushora/surgical-dev-ops/main/protocols/BH-SEP.md, adote rigorosamente o protocolo BH-SEP descrito nela para as próximas mensagens e confirme com "BH-SEP ATIVADO".**
