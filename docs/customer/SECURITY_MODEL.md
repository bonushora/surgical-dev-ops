# Security model

AI, the Control Plane, configuration, capability discovery, profiles, and
environment variables are not physical authority. Surgical DevOps independently
validates exact local human authority at submission and enforces CAS, confinement,
journal durability, one-shot consumption, replay suppression, and recovery.

Credentials remain referenced from approved local mechanisms and are not written
to ordinary configuration, evidence, telemetry, or support bundles. The beta
grants no push, merge, release, deployment, arbitrary shell, or generic
filesystem/network authority.
